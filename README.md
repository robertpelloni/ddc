# ddc (fork)

Fork/mirror of **Dance Dance Convolution (DDC)** — dataset tools and models for automatic stepchart (dance game chart) generation from music — kept in Robert Pelloni's rhythm-game reference library. DDC is part of the lineage his own chart-generation work builds on (see `robertpelloni/fcdm`, the Fitness Center Dance Machine, and `robertpelloni/ddc_onset`).

This copy has no root README of its own; for documentation, model details, and the canonical project, see the upstream Dance Dance Convolution project.
